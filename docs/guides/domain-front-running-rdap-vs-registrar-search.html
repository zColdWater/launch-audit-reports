Avoiding Domain Front-Running: Direct IANA RDAP vs. Registrar Search Bars

RDAP (Registration Data Access Protocol) is ICANN's official JSON replacement for port-43 WHOIS. Querying registry RDAP endpoints directly removes commercial middlemen when vetting startup names.

1. Query Verisign & Google Registry RDAP Directly

An HTTP 404 from an authoritative TLD RDAP server means the domain is unregistered in the central zone database; HTTP 200 returns structured registration and expiration timestamps.

# Authoritative .com RDAP lookup (zero intermediary):
curl -i https://rdap.verisign.com/com/v1/domain/your-startup-name.com

# Or check .com/.io/.ai/.co/.app/.dev + handles + USPTO in one CLI call:
npx github:zColdWater/brandshield-cli check YourStartupName

2. Watch Out for Registry-Reserved Premium Domains

For newer gTLDs like .ai, .io, and .app, a short 3–4 letter unregistered domain may still carry a registry premium tier price at checkout. Always verify final checkout pricing before announcing a brand.

Frequently Asked Questions

Does every TLD support RDAP?

Major gTLDs (.com, .net, .org, .app, .dev, .io, .ai, .xyz) publish official RDAP servers via IANA's dns.json bootstrap; legacy ccTLDs like .co fall back cleanly to registry port-43 WHOIS.
