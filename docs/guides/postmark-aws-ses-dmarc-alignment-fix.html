Fixing DMARC Alignment Failures on AWS SES, Postmark & Mailgun

DMARC does not pass just because SPF passes — the Return-Path domain (SPF) or d= signing domain (DKIM) must match the visible From: header domain.

1. Configure Custom MAIL FROM in Amazon SES

By default AWS SES signs Return-Path with amazonses.com, which passes SPF but FAILS DMARC SPF alignment. Configure a Custom MAIL FROM subdomain (e.g., bounce.yourdomain.com) AND enable Easy DKIM (3 CNAME records) so both paths align.

# AWS SES Custom MAIL FROM subdomain DNS:
MX   bounce.yourdomain.com   10 feedback-smtp.us-east-1.amazonses.com
TXT  bounce.yourdomain.com   "v=spf1 include:amazonses.com ~all"

2. Configure Custom Return-Path CNAME in Postmark

In Postmark's Sender Signatures panel, add both the DKIM TXT record and the pm-bounces CNAME pointing to pm.mtasv.net. Relaxed alignment (aspf=r; adkim=r) lets pm-bounces.yourdomain.com align cleanly with hello@yourdomain.com.
