3. 1. Why AI-Built Apps Leak Data — And What a Scanner Must Actually Inspect

The most common launch failure in Lovable, Bolt.new, v0, and Cursor projects is not an exotic zero-day exploit — it is shipping a PostgreSQL table in Supabase without ALTER TABLE ... ENABLE ROW LEVEL SECURITY (CVE-2025-48757), or prefixing an OpenAI, Anthropic, Stripe, or Supabase service_role secret with NEXT_PUBLIC_ or VITE_ so the bundler compiles it straight into public browser JavaScript.

Because modern Next.js and Vite builds split code across multiple lazy chunks, checking only the initial HTML misses most leaks. Yes. VibeShield is strictly read-only and non-destructive. It never inserts, updates, deletes, or dumps user rows from your database — it only inspects public client assets, HTTP headers, and PostgREST OpenAPI / HEAD metadata.
