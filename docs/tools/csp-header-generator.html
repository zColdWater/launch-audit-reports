Frequently Asked Questions

Why does Mozilla Observatory fail a CSP that includes script-src 'unsafe-inline'?

If an attacker injects an inline script tag via XSS, 'unsafe-inline' allows the browser to execute it immediately. Replacing 'unsafe-inline' with per-request nonces or SHA-256 hashes closes inline XSS execution.
